Edward's CMU OLI UI/UX Evaluation

  • Q: What is the URL of the website?
  • A:https://oli.cmu.edu/
  • Q: What is the name of the website?
  • A: Carnegie Mellon University Open Learning Initiative
  • Q: Who is the site's target audience
  • A: students and other learners
  • Q: How is the site organized?
  • A: It contains a navigation bar which links to courses, services and other information There is a large hero image that explains that it helps learners with science backed strategies and a link to the courses. Then, there is an explanation of how its materials use strong tactics to make learning more effective. After that there are several links paired with images that allow you to explore courses, learn about torus and information about learning engineers. The next section explains how they user a data driven approach to see where there are gaps and to see what is effective. News is then covered with several links. Partner organizations are then listed. Finally, there is a link to talk at the team and the footer which contains some of the links throughout the page. Each of the sections is separated in blocks with changing color and consistent alignemnt to give the feeling that each layer is separate.
  • Q: What is the audit score according to accessibility checker
  • A: The accessibility score for this website was 71%
  • Q: What is the site's effectiveness?
  • A: The site clearly explains its offerings and very clearly shows how to navigate with godd labeling.
  • Q: Does it support users in completing actions accurately?
  • A: actions are simple, the hierarchical nature of the site supports finding the appropriate material easiliy
  • Q: How is the engagement?
  • A: I would rate engagement as high, the user who wants to find a course is able to do so in a few number of clicks. For motivated self learners this seems very manageable.
  • Q: Is it pleasant to use and appropriate for its industry/topic?
  • A: I would say that simplicity is the strenght of this page. Anyone who wants to find a class that CMU OLI offers could do so without any friction.
  • Q: Make at least one recommendation to improve this website based on what you learned in this module
  • A: I think that the website uses more whitespace than I would, providing more information on each page would reduce the number of clicks necessary to navigate it.
